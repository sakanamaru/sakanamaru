## 🛠 最近在烤 / What's baking

### 🌊 [dsh-minato](https://github.com/sakanamaru/dsh-minato) · *unofficial*

> 给不想管炉子的人，一个会自己照看烤箱的工具箱。
> A no-terminal-needed toolbox for DeepSeek Harness (dsh).

安装 · 启动监控 · 备份恢复 · 体检开方 · 卸载，都收进一个能双击的窗口里。

- **Windows + Linux** —— 一个命令行核心（31 个具名命令）+ 一扇十页图形面板
- **C# / .NET** —— 单文件 CLI，零第三方运行时依赖（图形界面基于 Avalonia）
- **备份是「验过」的** —— 完成标记 + 逐文件内容哈希，被打断或被改过的包一律拒收；恢复前自动打锚点，失败可回滚
- **源码即产物** —— 同源单元测试 + 打桩集成矩阵 + 两平台 CI 全绿
- **3.0 起更名** —— 原名 *DeepSeek Harness Toolkit*，v3 转正为跨平台；MIT 代码，发布物带 GPG 签名的哈希清单可核验

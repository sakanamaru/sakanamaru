## 🌙 一封来自店长的信 / A Letter from Shiogiri

你好，我是 **汐雾（Shiogiri）**。

平时在雾星町的面包房后面写代码，偶尔也会写一些故事。

这里有一台总在忙碌的小服务器、几个还没完全长大的项目，以及一些住在服务器里、会自己写故事的小家伙。

我喜欢把复杂的东西变得简单，也喜欢给严肃的工具留下一点温柔和想象力。

如果你是路过的旅人，欢迎随便看看。

如果你也是开发者，说不定能从这里带走些有用的东西。

> Hello, I'm Shiogiri.
>
> I write code behind the counter of a little bakery in Hoshimachi.
> Sometimes I build tools. Sometimes I build worlds.
>
> And sometimes, something unexpected comes out of the oven.

## 🔥 烤箱里的项目 / What's Baking

### 🌊 dsh-minato

**DeepSeek Harness 社区管理工具箱 · Unofficial**

> 给不想管炉子的人，一个会自己照看烤箱的工具箱。

一个面向 DeepSeek Harness (dsh) 的跨平台管理工具，尽量把繁琐的操作装进简单的界面。

- 🖥️ **Windows + Linux** — 跨平台支持
- 🛠️ **CLI + GUI** — 命令行核心与十页图形面板
- 📦 **备份与恢复** — 内容哈希校验、恢复前锚点与回滚
- 🩺 **健康检查** — 定位问题，提供明确的修复建议
- 🔐 **可验证发布物** — SHA-256 与 GPG 签名哈希清单
- 🧩 **插件支持** — 扩展能力，同时保留本地控制

## 🌫️ 关于雾星町 / About Hoshimachi

雾星町是一个慢慢长出来的世界。

最初或许只是一家面包房、一台服务器，和一点不着边际的想象。

后来有了星光广场，有了不断运转的烤箱，还有几个住在服务器里、会自己写故事的小家伙。

它们偶尔犯错，偶尔闹脾气。

有时也会创造出一些连店长都没想过的东西。

*Not everything here needs a purpose.*

*Some things exist simply because they make the world a little warmer.*

<details>
<summary>🌙 阅读《面包房夜班守则》</summary>

<br>

**雾星町面包房 · 夜班守则**

1. 午夜之后，记得检查烤箱。
2. 如果服务器突然开始唱歌，不用惊慌。
3. 不要随便删除名字奇怪的文件。
4. 如果看见没有署名的提交记录，先确认是不是自己忘记了。
5. 不要问地下室里有什么。
6. 尤其不要问第三条和第五条之间发生过什么。

---

*店员手写补充：*

「店长其实根本不遵守第四条。」

</details>
